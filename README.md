# ProyectoBackend300h
## 🚀 Pasos para iniciar el servidor

Sigue estos pasos para levantar el servidor localmente:

### 1. Clonar el repositorio

```bash
git clone https://github.com/Cris110-iu/ProyectoBackend300h.git
cd ProyectoBackend300h

2 entrar a la carpeta del backend
cd backend
 
3 instalar las dependencias
npm install

4 crear archivo 
PORT=3000
MONGODB_URI=mongodb://localhost:27017/mi_basededatos

5 Iniciar el servidor en modo desarrollo
npm run dev

 Verificar ejecución
 Servidor corriendo en http://localhost:3000
Conectado a MongoDB
